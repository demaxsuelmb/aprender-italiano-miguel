# 🇮🇹 Corso di Italiano - Miguel

Bem-vindo ao seu repositório pessoal de estudos de Italiano! 

Este repositório contém todo o seu material teórico, anotações de estudo, exercícios e um **aplicativo web interativo** para apoio ao aprendizado com áudio nativo em italiano.

---

## 📂 Estrutura do Repositório

* `index.html` - Aplicação Web Interativa (Italian Learning Hub)
* `styles.css` - Estilos visuais elegantes em Dark Mode
* `app.js` - Lógica interativa, sintetizador de áudio (SpeechSynthesis API), flashcards e quiz
* `caderno_de_estudos.md` - Caderno teórico estruturado com regras gramaticais e exemplos

---

## 🚀 Como Executar o App de Estudos Localmente

1. Abra o arquivo `index.html` em qualquer navegador web moderno.
2. Navegue pelos módulos de teoria na barra lateral.
3. Clique no ícone de áudio 🔊 para ouvir a pronúncia nativa de qualquer palavra ou frase.
4. Utilize a aba de **Flashcards** para prática de memorização ativa.
5. Faça o **Quiz da Teoria** para testar a retenção dos conceitos.

---

## 📚 Módulos Teóricos Cobertos

1. **Fonética e Pronúncia**: Regras do C, G, H, GLI, GN, SC e Consoantes Duplas (*Doppie*).
2. **Gêneros e Artigos**: Regras dos substantivos (-o/-a/-e) e escolha dos artigos (*il, lo, la, l', i, gli, le*).
3. **Pronomes e Verbos Auxiliares**: Conjugação de *Essere* (Ser/Estar) e *Avere* (Ter/Haver).
4. **Conjugações Regulares**: Presente do Indicativo para verbos em *-ARE*, *-ERE* e *-IRE*.
5. **Sintaxe e Negação**: Omissão do sujeito e o uso do advérbio *NON*.
